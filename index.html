Questions, answered

What is Hoger for?

A harness for long agent orchestrations. See what each agent is doing, open it when needed, replay misses, and steer toward your goals.

Can I bring my own agents?

Yes. Hoger is the harness around the agents you already run. A run shows every subagent, how they fit together, and where you can step in.

Can more than one orchestration run at once?

Yes. Concurrent runs sit in their own lanes. You watch, schedule, and nudge each one.

Can I replay one agent without restarting the run?

Yes. Open the agent that missed, see what it did and why, and replay that branch. The rest of the run stays put.

Can I see token spend?

Yes. Spend across the nest, so you know the costly branch before the bill.

What happens to a run that lasts all day?

It stays on the board. Hours or days remain visible after you close the log.
